# ViaProto

## What This Is

ViaProto is an AI learning architect: you describe a goal and it generates a structured
learning path from fundamentals to mastery, where every step is backed by a real, verified
web resource. It targets professionals who need to upskill fast in an era of layoffs and
automation, and it is live in production at https://viapro.to.

## Core Value

A user describes a goal and receives a trustworthy, structured learning path where every
step links to a real, verified resource — not SEO-gamed filler.

## Business Context

- **Customer**: Professionals upskilling quickly (layoffs/automation era); solo and small teams.
- **Revenue model**: Stripe subscriptions — Pro ($12/mo or $100/yr) and Team ($10/seat/mo); Free tier as funnel.
- **Success metric**: Completed, resource-verified paths generated by paying accounts.
- **Strategy notes**: Solo-owner SaaS; owner pays AI inference costs (drives model-catalog policy).

## Constraints

- **Tech stack**: Next.js 15 async APIs must be awaited (params, headers, cookies, server `createClient()`) — Next.js 15 breaking change.
- **Infra**: Background worker MUST be running or generation stalls in `pending` indefinitely — worker is a separate process sharing `DATABASE_URL`.
- **Security**: RLS enforced on all core tables; service-role key is server-only and bypasses RLS — never expose it client-side.
- **Security**: Stripe webhook signatures MUST be verified via `constructEvent` before processing.
- **Validation**: All API inputs validated with Zod (ZodError→400, unauthenticated→401, unexpected→500).
- **Billing**: Rate-limit checks run BEFORE path creation; quota consumed at initiation, not completion.
- **Product rule**: Free-tier paths are always public (cannot be private); free tier limited to the 10 `minimumTier: "free"` models (code-verified — CLAUDE.md's "7" is stale).
- **Runtime**: Node.js 18+; Supabase CLI required for local DB.
